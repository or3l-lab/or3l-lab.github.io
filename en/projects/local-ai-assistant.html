    02The challenge

    Using AI every day on your own files and databases raises a simple question: where does the data go? With Orélia, nowhere. The assistant runs on a Windows PC with local models, and has to stay useful without ever losing its user's trust.

    03What it does

    • 01

      A conductor

      It receives the request and hands it to the most suitable agent: root cause, quality, databases… Each one has its own local model.

    • 02

      Two-level memory

      A global memory installed with the application, and a personal memory for each user. The personal one lives outside the installation and can be imported or exported.

    • 03

      Guardrails on files

      Allowed folders, read-only by default, preview and confirmation before any write.

    • 04

      Sourced answers

      Orélia separates what it has read from what it assumes, and says so when it could not verify.

    05What I learned

    • 01

      A local model only delegates probabilistically

      So I built a non-regression bench that measures the delegation rate after every change of model or prompt.

    • 02

      Measure before optimising

      The agent profile was replayed on every turn. Once measured and fixed, context dropped by 15 to 40% on real conversations, without touching the guardrails.
