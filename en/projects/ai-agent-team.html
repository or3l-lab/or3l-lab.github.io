    02The challenge

    Maintaining a large application portfolio takes time. The goal is to increase capacity for design, development, testing and documentation without losing human oversight.

    03What I did

    • Organised nine specialised agents coordinated by an orchestrator.
    • Shared working rules, project memory and quality criteria.
    • Set up a reversible release workflow, so changes can be rolled back.
    • Kept a person involved in supervising and approving every release.
