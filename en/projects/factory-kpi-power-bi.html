02The challenge

In a factory, each department has its own tools, files and habits. Without a shared reference, everyone computes indicators separately, and the figures diverge.

  • Bring the data together in a single report, open to every department.
  • Check its quality, so that everyone can rely on it.
  • Refresh it automatically, with no manual rework.

Typical friction points

01

Figures that diverge

Two departments report different results for the same indicator: the meeting is about the numbers rather than the decisions.

02

Files reworked by hand

Every update means copy-pasting and corrections, with the risk of error that comes with it.

03

Anomalies found too late

A missing or duplicated value is only spotted once the decision has been made.

04

Indicators that are hard to share

A personal dashboard only serves its author: other departments cannot see it, or do not trust it.

04What the report covers

The report covers the main industrial performance topics, each with its own analysis pages.

Store inventory

Stock levels and movements, to follow what is available and what is moving.

Production and management

Transactions, management variances, material variances and item history.

Scrap

Scrap tracking, from production management and shop-floor time tracking.

Time and efficiency

Recorded time, efficiency, out-of-routing, idle time and time-entry errors.

Workload plan

Load per work centre, expressed in hours.

Data quality

A checking page that spots anomalies and measures how reliable the figures are.

05Power Query

Power Query prepares the data before it reaches the model. Each transformation is recorded once, then replayed at every refresh.

  1. Connecting to sources

    SQL databases, a reference Excel file and parameters, brought together in one place.

  2. Typing and renaming

    Each column gets a data type and a clear name.

  3. Filtering and de-duplication

    Unneeded, empty or duplicate rows are removed.

  4. Joins

    Tables are matched with one another, including the reference file.

  5. Calculated columns and grouping

    Derived values are computed at source, then aggregated at the right level.

  6. Shared calendar

    A common date table to analyse every topic over the same period.

06Data quality checks

A dedicated report page checks the data before anyone relies on it: we no longer assume it is good, we measure it.

  • Anomaly rate
  • Total anomalies
  • Critical anomalies
  • Rows checked
  • Amount affected

The checks cover transactions, scrap and costs. The values in the demo are fictional.
